# 🀄 麻将大师 · 豪华翡翠雀台 (Mahjong Master)

跨平台（iOS / Web / Android）四人在线联机对战麻将应用。  
支持 **特色「飛」万能牌**、**8张花牌补花与花杠**、**听牌推荐助手**、**Web Audio 逼真牌桌敲击音效**、**局内互动表情与短语**、**4位房号与二维码邀请** 以及 **PWA / Capacitor 原生安装**。

---

## 🌟 核心特色与升级

### 1. 🎨 豪华翡翠雀台与 3D 立体象牙牌
- **视觉风格**：典雅温润的翡翠绿呢绒桌布，搭配实木烤漆边框与金边勾勒，带来沉浸式传统高级麻将馆质感。
- **3D 立体麻将牌**：细腻象牙白正面、碧玉绿背面与立体倒角阴影；手牌上浮选中、相同牌全桌高亮，记牌防守一目了然。
- **动态 3D 罗盘与 15s 倒计时**：中心八卦罗盘转盘实时指示当前风向（东/南/西/北）与出牌方呼吸光环，环形 15 秒倒计时并在最后 5 秒伴随警报心跳律动。

### 2. 🧠 听牌提示助手（Ting Assistant）
- 自动分析手牌构型（包含 4 张「飛」万能牌及七对牌型）。
- 轮到出牌时，可听牌的手牌右上角自动浮现金色 **「听」** 徽标。
- 点击手牌即时展开悬浮提示卡：显示打出此牌后所听的全部目标牌（例如：`打出【三万】：听【二条(剩3张), 五条(剩1张), 飛(剩2张)】，共 6 张`），新手老手皆能得心应手。

### 3. 🔊 Web Audio 原生音效与古风五声音阶背景音乐 (BGM)
- **国风环境背景音乐**：内置基于 Web Audio API 的中国传统五声音阶（宫、商、角、徵、羽）合成器，模拟古筝、琵琶弹拨与悠扬竹笛空灵垫音，支持音量滑块微调与工具栏快捷一键静音开闭，完全零外部音频文件加载依赖，离线秒开！
- **原生牌桌逼真音效**：
  - **摸牌选牌**：清脆短促的高频陶瓷轻碰声。
  - **落桌打牌**：沉稳有力的木呢绒桌面敲桌声（「啪！」）。
  - **吃 / 碰 / 杠 / 胡**：霸气古筝/铜锣与大调胜利赞歌音效。
  - **倒计时预警**：最后 5 秒急促木鱼节拍提示。

### 4. 🎴 进入游戏模式选择面板（单人练习 vs 多人联机）
- **绝不盲目开局**：进入游戏时优先呈现沉浸式**【模式选择】**界面，玩家自主选择：
  - **👤 单人练习模式**：3 位智能雀神 AI 快速对局，自动开启金色听牌辅助，断网也能畅玩。
  - **👥 好友多人联机**：快速进入联机大厅，支持 4 位房号与二维码扫码入座，全员准备就绪后由房主开赛！
- **大名与随机昵称**：面板内支持直接输入你的雀神大名，配备 **🎲 随机按钮**（如「雀仙发哥」「天胡一色」「十三幺」等趣名），自动保存。
- **随时切换模式**：顶部工具栏新增 **`[🏠 模式]`** 按钮，任何时候均可一键呼出模式选择面板自由切换。

### 5. 🌐 多端联机与房间就绪系统（iOS / Android / Web）
- **房内全员准备机制**：房主创建房间后，其他入座玩家点击【✋ 准备】/【✅ 已准备】；房主的【🚀 开始游戏】按钮实时受控，必须在全部入座玩家就绪后才允许开赛，保障公平竞技！
- **4 位极简房号**：支持一键生成与输入，未满四人开始时自动由高智商机器人平滑补齐。
- **一键复制链接与扫码加入**：内置离线 Canvas 二维码生成器，面对面聚会手机相机扫码即可直达房间。
- **局内互动**：悬浮快捷气泡支持常用语（「快点出牌啊，花儿都谢了！」「这把我要自摸～」）与动态表情互动。

### 6. ⚡ 强健断线无缝重连与对局状态保护系统 (Match Recovery & Seamless Reconnect)
- **断线不重开，对局完整保全**：无论房主或玩家因移动网络切换、锁屏、意外刷新或丢包掉线，绝不强制重开，随时重连归队继续对战！
- **持久化客户端凭证（Persistent Client ID）**：自动为每位玩家生成并持久化唯一凭证，避免页面刷新后匿名 ID 漂移，精准识别并重新绑定原有座位、手牌及番数。
- **60秒断线等待缓冲（Grace Period）**：成员掉线时显示浮动提示胶囊，房主离线时提供 60 秒宽限期，由高智商 AI 临时托管代打维持牌局流转，避免房间瞬间解散。
- **智能未完成对局恢复弹窗**：刷新或重新打开网页/App 时，自动侦测 2 小时内的活跃对局，弹出【⚡ 发现未完成的对局】卡片，一键即可秒速无缝重连回桌！
- **房主全量牌局快照快照固化**：房主端在摸打、吃碰杠、同步时自动全量固化牌墙剩余张数、各家暗牌明牌、总积分及回合行动队列，即使断网刷新亦能一键复原整桌牌局！

## 📜 详细玩法规则

| 规则项 | 详细说明 |
| :--- | :--- |
| **基础牌数** | 共 148 张（万、条、筒各36张，东南西北中发白28张，4张「飛」万能牌，8张花牌）。 |
| **「飛」万能牌** | 4张金色的「飛」为百搭牌，可代替任意牌组成顺子、刻子、杠牌或将牌。 |
| **花牌补花** | 摸到春夏秋冬、梅兰竹菊自动置于花牌区，并从牌墙尾部摸一张补牌。 |
| **花杠即时结算** | 集齐一组花牌（春夏秋冬 或 梅兰竹菊）即算花杠：<br/>· **天花杠**（起手集齐）：每家付 4 分（共+12分）。<br/>· **局中花杠**（摸牌集齐）：每家付 2 分（共+6分）。当下即刻结算入分。 |
| **杠牌即时结算** | · **暗杠**：其他三家各给 4 分（共+12分）。<br/>· **明杠 / 补杠**：其他三家各给 2 分（共+6分）。 |
| **胡牌计分** | · **自摸胡**：三家各付 4 分，赢家得 12 分。<br/>· **点炮胡**：点炮者付 4 分，另外两家各付 2 分，赢家共得 8 分。<br/>· **流局**：牌墙摸尽无人胡牌，本局不计分。 |
| **过水规则** | 别人打出的牌能胡却点了「过」，即进入过水状态——在下一次轮到自己摸牌前不能胡任何人打出的牌；摸牌出牌后自动解除。自摸不受过水限制。 |

## 📁 项目工程架构

```
.
├── index.html              # 游戏主入口（自适应横屏视口、牌桌结构、模态框）
├── style.css               # 豪华翡翠雀台样式、3D 象牙牌面、动画特效、移动端适配
├── app.js                  # 游戏主逻辑控制器、状态机、回合流程、倒计时、事件绑定
├── engine.js               # 麻将规则引擎、4飞万能牌胡牌判定、听牌计算助手、AI出牌
├── audio.js                # Web Audio API 牌桌原生音效合成器（敲桌声、吃碰杠胡、警报）
├── network.js              # Supabase Realtime 联机房间、状态同步、表情聊天广播
├── qr.js                   # 纯前端轻量二维码渲染器（支持手机相机扫码秒进房）
├── icon.svg                # 经典金色「發」字 3D 麻将高清应用图标
├── manifest.webmanifest    # PWA 清单配置（支持横屏锁定与手机桌面安装）
├── sw.js                   # Service Worker 离线缓存
├── capacitor.config.json   # Capacitor 原生 Android/iOS 移动端配置
└── package.json            # 项目配置与本地运行脚本
```
